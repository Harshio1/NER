From a voice to a tag, in five steps

  1. Record. Ten short sentences, each with at least one person, organisation or place; three more for testing.
  2. Transcribe. Whisper turns each .wav into text; word error rate is measured against the script.
  3. Annotate. Entities are marked by hand and converted to BIO tags: B-PER, I-PER, B-ORG, I-ORG, B-LOC, I-LOC, O.
  4. Train. Word and suffix embeddings feed a bidirectional recurrent layer; a softmax gives one tag per word. SimpleRNN, LSTM and GRU are all implemented.
  5. Evaluate. Strict entity matching (type and exact span) on new recordings, with and without capital letters.

What goes wrong with a tiny, self-made audio dataset

Almost no data

Ten sentences hold 75 words and 21 entities. Trained on those alone, the model scores far below the augmented one, and its score swings widely between random seeds.

Augmentation helps and misleads

Substituting entities into templates teaches context patterns, but the synthetic sentences share a few dozen phrasings. Training loss falls close to zero, which signals memorised templates more than language understanding.

Names the model has never met

Unseen words fall back to the unknown-word vector, so the decision rests on context and word endings. Where the context is ambiguous the label is a guess, which is how an organisation can come out as a location.

Speech-to-text removes clues

Some engines drop capital letters and punctuation, and may mishear or split rare names. The model is trained with capitalisation randomly removed, yet every ASR mistake becomes a label mistake.

One speaker, one accent

All the audio is a single voice in a quiet room. Other accents, noise and speaking speeds change the transcripts, and none of that is tested here.

Three test sentences

One wrong entity moves F1 by more than ten points. Treat the numbers as a demonstration of method, not a benchmark.

Run it yourself

pip install -r requirements.txt
python src/transcribe.py --audio audio/train          # speech to text
python src/annotate.py build --in data/sentences.tsv --prefix data/annotated_train
python src/train_keras.py --cell all                  # SimpleRNN vs LSTM vs GRU
cd src && python run_experiments.py                   # NumPy BiGRU, ablation, website export
python src/predict_audio.py audio/test/test_01.wav    # tag a new recording
